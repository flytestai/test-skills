# market-screenshot-compare

`market-screenshot-compare` 是一个用于对比行情截图的 skill。它适合新旧行情截图、同类行情页面、不同软件行情页面的差异核对，重点检查相同字段里的数值和行情数据是否一致。

## 主要能力

- 对比两张截图中相同字段的内容
- 重点检查字段里的数值、价格、涨跌幅、成交量、总市值等行情数据
- 忽略背景颜色、排版、主题皮肤、控件样式等纯视觉差异
- 自动判断盘中和盘后，采用不同严格度
- 支持不同软件之间的行情对比
- 输出适合开发和测试使用的精简 bug 标题

## 核心规则

### 1. 只关注相同字段的差异

- 先找两张图里都能看到的字段
- 再比这些字段对应的值
- 不把字段名相同但值不同的内容漏掉
- 不把样式差异误报成数据差异

### 2. 不只是字段名，还要比字段值

重点检查字段里的实际行情数据，包括但不限于：

- 价格
- 涨跌
- 涨跌幅
- 成交量
- 成交额
- 最高价
- 最低价
- 今开
- 昨收
- 均价
- 换手率
- 总股本
- 流通股本
- 总市值
- 流通市值
- 排名
- 百分比
- 空值占位符，如 `--`、`nan`、`0.00%`

### 3. 盘中 / 盘后模式

skill 会结合截图时间自动判断是盘中还是盘后。

盘后规则：

- 所有相同字段必须完全一致
- 只要有一个字段不同，就要报问题

盘中规则：

- 允许部分实时字段出现小幅波动
- 如果差异属于截图前后时间导致的合理波动，可以不报
- 如果一边有值，另一边没值，默认一定是问题
- 对于稳定字段，盘中也要严格检查

盘中时间范围：

- A 股：交易日 `09:30-11:30`、`13:00-15:00`
- 港股：交易日 `09:00-12:00`、`13:00-16:00`
- 其他时间默认按盘后处理

### 4. 不同软件对比

- 如果两张截图不是同一个软件，忽略版式和视觉风格
- 只比两边都能识别出来的共享字段
- 字段语义一致即可对比，不要求位置一致

### 5. 重复 bug 处理

- 默认每次截图都输出当前发现的 bug
- 如果是之前已经报过的同类 bug，先和用户确认是否需要重复报
- 只有用户明确说“不需要重复报”时，才进行去重
- 去重时按问题类型合并，不按具体数值拆成多个问题

### 常见输出风格

- 完整差异报告
- 不一致汇总
- 可疑问题清单
- 仅输出问题标题

## OCR 增强

这个 skill 内置了 OCR 增强流程，用于提高字段识别率。

- 优先识别截图中的原始字段名
- 对看不清的字段明确标记“未能确认”
- 尽量先识别数值，再做字段对齐
- 重点减少漏检最高价、最低价、今开、昨收、总市值、流通市值等关键字段

## 典型判定

以下情况通常应当报问题：

- 同一字段一边有值，另一边没值
- 同一字段数值明显不同
- 百分比、单位、空值占位符表现不一致
- 排名、总市值、流通股本等稳定字段不一致

以下情况通常可以忽略：

- 纯背景颜色变化
- 主题皮肤变化
- 排版间距变化
- 右下角时间差异
- 盘中实时字段的小幅合理波动

## 备注

- 这份 skill 的目标是尽量完整地找出真正的数据差异
- 如果字段看不清，必须明确说明，不能默默跳过
- 若用户明确要求不重复报同类 bug，再启用去重
